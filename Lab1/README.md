## Обязательные функции (API проекта)

### 1) Служебные функции

#### Инициализация массива (параметризованный диапазон)

```cpp
void initArray(double* a, int n, double minValue, double maxValue);
```
Примеры вызова:
```cpp
initArray(arr, n, -10.0, 10.0);
initArray(arr, n, -5.0, 25.5);
```
Вывод массива
```cpp
void printArray(const double* a, int n);
```
Назначение: Выводит элементы массива в одну строку.

### 2) Функции преобразования массива (по индивидуальному варианту)

> Вариант определяет какую часть массива нужно менять.
> Реализация может быть:
> - через передачу (begin, end),
> - через выделение индексов внутри функции,
> - через вспомогательную функцию вычисления диапазона.   
> Главное: результат должен соответствовать варианту.

Примены прототипов фнкций:

- Зеркальная перестановка (реверс)
```cpp
void reverse(double* a, size_t n, size_t start, size_t end);
```
    Выполняет зеркальную перестановку заданной части массива (Часть 1).

- Циклический сдвиг влево на k позиций в части массива
```cpp
void cyclicLeftShift(double* a, size_t n, size_t k, size_t start, size_t end);
```
    Выполняет циклический сдвиг заданной части массива влево на k позиций (Часть 2).

- Сортировка по возрастанию части массива (алгоритм по выбору преподавателя)
```cpp
void selectionSort(double* a, size_t n, size_t start, size_t end);
```
    Сортирует заданную часть массива по возрастанию методом выбора (Часть 3).

#### Демонстрационный режим работы программы
Программа должна:
- Считать `n` (размер массива)
- Считать `minValue` и `maxValue` (диапазон генерации)
- Выделить динамический массив `double* a = new double[n]`
- Вызвать `initArray(a, n, minValue, maxValue)`
- Вывести:
    - метку этапа,
    - массив (через `printArray`)
- Выполнить Часть 1 (реверс заданной части) → вывести результат
- Выполнить Часть 2 (циклический сдвиг заданной части) → вывести результат
- Выполнить Часть 3 (сортировка выбором заданной части) → вывести результат
- Выполнить Часть 4 (автотесты без фреймворков) → вывести результаты тестов
- Освободить память `delete[] a`

#### Обязательный формат вывода тестов (НЕ МЕНЯТЬ)
Каждый тест выводит строго одну строку:
```
[TEST] <имя теста>: PASS
```
или
```
[TEST] <имя теста>: FAIL
```

Вспомогательные функции для тестов (рекомендуемый минимум)
Добавьте в `main.cpp` (или `tests.cpp`):

```cpp
#include <cmath>
#include <iostream>
#include <string>
using namespace std;

bool equals(double a, double b, double eps = 1e-6) {
    return fabs(a - b) < eps;
}

void printTestResult(const string& testName, bool result) {
    cout << "[TEST] " << testName << ": "
         << (result ? "PASS" : "FAIL") << endl;
}
```

##### Обязательные тесты
1) `initArray` — проверка диапазона
Тест не должен зависеть от конкретных случайных значений.
Проверяем только то, что все элементы лежат в диапазоне.

```cpp
bool testInitArrayRange() {
    double a[5];
    initArray(a, 5, -1.0, 1.0);

    for (int i = 0; i < 5; ++i) {
        if (a[i] < -1.0 || a[i] > 1.0) return false;
    }
    return true;
}
```

2) `reverse` — тест на фиксированном массиве

```cpp
bool testReverseFullArray() {
    double a[] = {1, 2, 3, 4, 5};
    double expected[] = {5, 4, 3, 2, 1};

    reverse(a, 5);

    for (int i = 0; i < 5; ++i) {
        if (!equals(a[i], expected[i])) return false;
    }
    return true;
}
```

3) `cyclicLeftShift` — тест на фиксированном массиве

```cpp
bool testCyclicLeftShift() {
    double a[] = {1, 2, 3, 4};
    double expected[] = {2, 3, 4, 1};

    cyclicLeftShift(a, 4);

    for (int i = 0; i < 4; ++i) {
        if (!equals(a[i], expected[i])) return false;
    }
    return true;
}
```

4) `selectionSort` — тест на фиксированном массиве

```cpp
bool testSelectionSort() {
    double a[] = {3.5, -1.2, 7.0, 0.0};
    double expected[] = {-1.2, 0.0, 3.5, 7.0};

    selectionSort(a, 4);

    for (int i = 0; i < 4; ++i) {
        if (!equals(a[i], expected[i])) return false;
    }
    return true;
}
```

Рекомендуемый автопроверяемый блок `main()` для тестов
Этот блок можно запускать после демонстрационного режима или даже отдельным режимом (например, оформить в виде меню).

```cpp
int main() {
    // ---------------------------
    // ДЕМО (обязательное)
    // ---------------------------
    int n;
    double minValue, maxValue;

    cin >> n;
    cin >> minValue >> maxValue;

    double* a = new double[n];
    initArray(a, n, minValue, maxValue);

    cout << "Исходный массив:\n";
    printArray(a, n);

    cout << "\nПосле Часть 1 (reverse):\n";
    reverse(a, n);
    printArray(a, n);

    cout << "\nПосле Часть 2 (cyclicLeftShift):\n";
    cyclicLeftShift(a, n);
    printArray(a, n);

    cout << "\nПосле Часть 3 (selectionSort):\n";
    selectionSort(a, n);
    printArray(a, n);

    delete[] a;

    // ---------------------------
    // ТЕСТЫ (обязательное)
    // ---------------------------
    printTestResult("initArray range", testInitArrayRange());
    printTestResult("reverse full array", testReverseFullArray());
    printTestResult("cyclic left shift", testCyclicLeftShift());
    printTestResult("selection sort", testSelectionSort());

    return 0;
}
```
